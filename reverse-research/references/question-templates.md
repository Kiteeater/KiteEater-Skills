# Question Templates

Use these templates to sharpen the research path. Do not dump them all at once. Pick the smallest set that will most change the decision.

## Competitor Deconstruction

Use when the user wants to understand how a market is actually won.

### Unspoken Insight

- "这些成功玩家真正理解、但客户不会直接说出来的东西是什么？"
- "竞品首页承诺的价值，和评论区里真实抱怨暴露的价值，差在哪？"
- "用户表面上说要功能，实际是在为哪种结果或风险缓释买单？"
- "这些产品没写出来但必须偷偷做得很好的能力是什么？"

### Consensus Fragility

- "这个市场默认的产品形态或收费逻辑是什么？"
- "头部玩家的护城河建立在哪三个默认前提上？"
- "如果迁移成本、集成成本或组织惯性没有想象中那么高，现有格局会怎样变？"

### Investor-grade Stress Test

- "为什么用户不直接用更便宜、更通用、或现有流程凑合？"
- "如果头部玩家明天降价或免费，这个机会还剩什么？"
- "你说的差异化，是同场景做得更好，还是解决了别的任务？"

## Market Entry

Use when the user wants to enter a geography, vertical, or customer segment.

### Unspoken Insight

- "本地成功者懂但外来者常常忽略的规则是什么？"
- "客户表面说需要本地化，背后真正想降低的风险或协调成本是什么？"
- "哪些关系、信任机制或分销习惯没有写在任何官网上？"

### Consensus Fragility

- "这个市场默认必须靠线下、渠道、认证、关系网络才能赢吗？"
- "规模经济、品牌信任、或合规门槛真的像大家说的那么强吗？"
- "什么变化会让现有进入壁垒突然变薄？"

### Investor-grade Stress Test

- "为什么之前的进入者失败了，真因是什么？"
- "如果你有无限预算，能买下市场份额吗？为什么不能？"
- "这个市场的 winner-takes-most 程度到底有多高？"

## Startup Idea Validation

Use when the user wants to decide whether a product or company idea is worth pursuing.

### Unspoken Insight

- "目标用户现在用什么凑合方案解决这个问题？"
- "他们愿意为解决方案付费，是为了省时间、省风险、涨收入，还是为了身份信号？"
- "用户已经忍了很久但很少直说的摩擦点是什么？"

### Consensus Fragility

- "这个想法默认用户愿意改变什么行为？"
- "这个市场默认哪个指标最重要，而那个指标可能根本不是购买驱动？"
- "为什么现在还没有赢家，这说明机会大，还是说明需求不够痛？"

### Investor-grade Stress Test

- "如果 Google、Microsoft 或头部平台明天做了这个功能，你还剩什么？"
- "这个增长引擎如果不 work，第二增长引擎是什么？"
- "真正愿意掏钱的人是谁，不掏钱的人又是谁？"

## User Pain Discovery

Use when the user wants to understand jobs-to-be-done, complaints, or unmet needs.

### Unspoken Insight

- "用户说自己在抱怨什么，但他们真正试图避免的后果是什么？"
- "哪些 workaround 最能说明需求强度？"
- "哪些高频抱怨看似是功能问题，实际是协作、信任或学习成本问题？"

### Consensus Fragility

- "团队默认用户最在乎速度、价格或易用性，但证据真的支持吗？"
- "用户当前忍受的限制，在什么条件下会突然变得不可接受？"
- "哪个痛点其实只影响小众重度用户，却被误当成普适问题？"

### Investor-grade Stress Test

- "这些抱怨真的会转化成付费，还是只会转化成吐槽？"
- "这个痛点出现频率高，但严重程度够高吗？"
- "如果用户已经形成稳定 workaround，为什么现在会切换？"

## Business Model And Due Diligence

Use when the user wants to inspect whether an opportunity is structurally sound.

### Unspoken Insight

- "真正驱动收入质量的，不是台面上的什么指标，而是什么？"
- "客户看起来在买产品，实际上是在买哪个商业结果或组织安心感？"
- "公司最值钱的能力，是产品、分销、服务，还是某种隐藏运营机制？"

### Consensus Fragility

- "这个 business 默认建立在什么单位经济模型上？"
- "如果留存、扩张、获客成本或 payback 的关系变了，模型会在哪先断裂？"
- "市场把哪个指标当健康信号，而那个信号可能被表象误导？"

### Investor-grade Stress Test

- "如果增长放缓，哪些优势会先暴露成脆弱点？"
- "哪些收入看起来可重复，其实更像一次性项目收入？"
- "什么证据会让一个严格投资人从 '有兴趣' 变成 '直接放弃'？"

## Prompt Fragments By Output Need

Use these when the user asks for a specific deliverable.

### If They Need A Research Path

- "先列出最该验证的 3 个假设，再给最省时间的取证顺序。"
- "只推荐最可能改变判断的下一批材料，不要列全量清单。"

### If They Need Opportunity Discovery

- "先指出市场共识的脆弱点，再说 openings，不要直接头脑风暴创意。"
- "把机会写成 '如果 X 前提不成立，谁会首先受益' 的形式。"

### If They Need A Judgment Memo

- "只基于现有材料形成阶段性判断，并明确哪些仍是猜测。"
- "每个核心结论都标注来自哪类材料。"
