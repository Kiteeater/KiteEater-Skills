# Output Templates

Use these templates to keep answers stable across different input depths.

## Compressed Template

Use for light asks or first-pass framing.

```markdown
# Reverse Research: [对象]

## Decision Question
[需要决定什么]

## Known / Unknown
- Known:
- Unknown:

## Core Assumptions
1. [...]
2. [...]
3. [...]

## Unspoken Insight
[成功玩家理解但客户不会直说的东西]

## Consensus Attack Surface
- 默认前提：
- 失效条件：
- 可能 opening：

## Investor Stress Test
1. [...]
2. [...]
3. [...]

## What To Inspect Next
1. [...]
2. [...]
3. [...]
```

## Writing Rules

- Prefer concise sections over long narratives.
- Use source types when exact citations do not exist yet.
- Label uncertainty directly.
- If materials are thin, do not fake a conclusion. Strengthen the question and the evidence plan instead.
